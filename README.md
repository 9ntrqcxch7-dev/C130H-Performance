# C-130H Performance Suite

Digitala prestandaräknare för C-130H från SMP 777 / FOM-B.

## Moduler

- **Max Effort Take-Off** — Maximal startmöjlighet, vridmoment, startfaktor, minsta fältlängd, vägrande hastighet, start- och hinderpasseringshastigheter
- **Hot Brakes** — Bromsenergiberäkning, resulterande bromstemperatur och avkylningstid
- **Max TOW** — Maximal tillåten startvikt (klimbgräns, fältlängdgräns, strukturell gräns, crosswind-rådgivning)

## Deployment

Deployad på Netlify: https://c130hperformance.netlify.app

Deploymentet är automatiserat från main-branchen i detta repo.

## Ansvarsfriskrivning

**Referensverktyg under utveckling.** Inte certifierat för operativ flygplanering. Digitaliserat från SMP 777 / FOM-B — se respektive verktygs egen ansvarsfriskrivning.
